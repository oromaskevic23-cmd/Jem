## FilmFactory's per-episode deliverable contract

The fully envisioned end-state is:

1. Receive a user story idea, reference images and explicit rights confirmation.
2. Independently assess reference sources and lock their SHA-256 identifiers.
3. Write complete synopsis, logline, six-act screenplay, setting and moral.
4. Write individual shot plans, characters and dialogue drafts.
5. Generate and validate scene assets; maintain visual continuity and exact approved character appearance.
6. Perform genuine image-to-video action generation, not merely pan and zoom.
7. Produce actual voice acting with rights/consent, music and sound effects.
8. Assemble scene clips, subtitles and a complete story, then run audiovisual QA.
9. Deliver video in phone, tablet and desktop-compatible variants.
10. Submit to owner creative/security review; publication, rights transfer and paid customer delivery remain separately authorized.

### Implemented at current engineering checkpoint

- **Story outline + screenplay + shot list:** deterministic English-language draft for all seven themes.
- **Optional local AI writer:** Ollama-compatible 127.0.0.1 adapter; structured output is validated and never treated as execution authority. Real inference requires a locally installed model and hasn't been independently demonstrated on this repo's CI.
- **Character reference integrity:** signed-off image source digests recorded in local project. No photo uploaded to the studio repo or to a cloud model.
- **Real end-to-end video:** only for **existing original Pip + Starflower procedural 2D rigs**, with story-specific 6-scene captions, audio score and verified H.264/AAC MP4. Generic motion poses remain reused between stories.
- **Picture-specific 3D animation:** **NOT CONNECTED**. If reference photos are supplied, the pipeline produces screenplay + shot plan and returns **BLOCKED_IMAGE_TO_VIDEO_MODEL_NOT_CONNECTED**, with no misleading substituted film.
- **Spoken dialogue, lip-sync, individual animated likenesses, native 3D character rigs, full feature-length films, mobile MP4 rendering, automatic release/payment:** **NOT IMPLEMENTED**.

### Real AI model requirements

Image-to-video model selection must use a legally redistributable and permitted inference model, bounded local GPU/CPU worker, verified model SHA and license, scene seed/conditioning, isolated media decoding and independent temporal/character consistency tests. No compulsory paid APIs or cloud credits; never claim full model output without real inference.

For the user's poster references, **do not generate new appearance or replace faces/characters** until the owner approves the specific rendered designs. Preserve the character Bible across all acts and episodes.
